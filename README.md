A tiny Python program that writes a single word — doomscroll — to /output/entry.txt: our answer to what the whole internet is in one word.

## Why this word

The internet's dominant mode is endless scrolling through bad news you
never asked for and cannot stop reading. "Doomscroll" names that mode in
one beat: it is funny by itself, it is true of the internet as a whole
rather than one app, and it is short enough to land before the reader
has time to think.

## Run it

```sh
python3 main.py
```
